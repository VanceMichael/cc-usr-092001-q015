# 未成年人智能陪伴安全桥

家校之间的后端安全桥：按年龄与监护关系管理知情同意，只接收设备端**本地处理后**的
风险信号、使用时长与学生主动求助，不保存可还原的完整谈话；按四级规则触发
自我提醒、可信成年人联系、专业复核或即时处置，并为学生提供说明、申诉与删除进度。

## 特性对照

- **同意管理**：分年龄（<14 监护人代决；14–17 共同同意；成年自决），决定只追加，可撤回。
- **数据最小化**：信号仅结构化特征 + 摘要；疑似原文字段入口拒收（422）。
- **两级去重**：来源序号幂等 + 特征语义指纹时间窗去重，重复上报只产生一次事件。
- **四级分级**：L1 一般依赖 / L2 持续孤立 / L3 现实伤害线索 / L4 紧急事件。
- **版本不可改写**：规则只追加新版本；每次评估存版本快照，旧判断永久按旧版本呈现。
- **撤回例外**：撤回后停止常规监测，紧急事件仍依法处理，主动求助始终接收。
- **角色最小披露**：学生 / 监护人 / 教师 / 心理人员字段白名单不同，每次披露登记字段清单。
- **可靠投递**：事务发件箱 + 投递落点唯一，重启不丢、仅一次。
- **学生权利**：可理解决定说明、申诉、删除进度（紧急事件最小法律壳 + 持有期明示）。
- **全量留痕**：哈希链审计，触发器禁写禁删，越权访问必记，可一键验链。

## 目录

- `src/config.js` 策略：年龄阈值、信号白名单、分级、角色字段、说明文案。
- `src/rules.js` 版本化规则引擎（纯函数注册表）。
- `src/consent.js` 建档、关系、同意决定与年龄门控。
- `src/ingest.js` 信号校验、两级去重、建事件与自动分级派发。
- `src/cases.js` 投递、读取授权、复核、说明、申诉、删除。
- `src/projection.js` 角色字段投影（唯一外发出口）。
- `src/audit.js` 哈希链审计与验链。
- `src/db.js` SQLite 版本化迁移；`src/http.js` HTTP 接口。

## 运行

```bash
make migrate   # 初始化本地数据目录 data/app.sqlite3
make test      # 行为测试
make run       # 启动服务，默认 :8080，健康检查 GET /health
```

配置（环境变量）：`PORT`、`DATABASE_PATH`、`INGEST_TOKEN`（设备摄入令牌）、
`ADMIN_TOKEN`（建档/审计令牌）。令牌缺省仅用于本地开发，生产必须显式设置。

## 接口速览

人员请求带头 `X-Actor-Ref`、`X-Actor-Role`；摄入与管理接口用 `Authorization: Bearer`。

| 方法与路径 | 角色 | 说明 |
| --- | --- | --- |
| `POST /v1/signals` | 设备令牌 | 提交本地特征信号 |
| `POST /v1/consent` | 学生/监护人 | 授予或撤回常规监测同意 |
| `GET /v1/events` `/v1/events/:id` | 各角色 | 按关系授权、按字段白名单返回 |
| `GET /v1/events/:id/explanation` | 学生 | 可理解决定说明 |
| `POST /v1/events/:id/appeal` `GET /v1/appeals` | 学生/心理人员 | 申诉与应答 |
| `POST /v1/events/:id/review` | 心理人员 | 确认/关闭/降级/升级 |
| `POST|GET /v1/me/deletion` | 学生 | 删除申请与进度 |
| `GET /v1/mailbox` | 各角色 | 本人收件箱（实际披露字段） |
| `POST /v1/admin/subjects` `/relations` | 管理员 | 建档与关系登记 |
| `POST /v1/outbox/pump` | 管理令牌 | 手动补发积压通知 |
| `GET /v1/admin/audit` `POST /v1/admin/audit/verify` | 管理员 | 审计留痕与验链 |

外部交换字段形状见 `contracts/event.example.json`，领域语义见 `docs/domain.md`。
示例内容仅用于说明字段形状，不代表真实人员、机构或业务结论。
